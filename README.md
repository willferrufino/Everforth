# Federal Digital Content & Accessibility Portfolio

A collection of federal-style web content and accessibility samples created to demonstrate experience with **Section 508, WCAG, plain language, content governance, accessibility remediation, QA, CMS publishing workflows, and front-end development**.

> **Portfolio Note:** These are independent portfolio concepts created for demonstration purposes. They are not official Department of Homeland Security (DHS) websites, documents, or publications.

**[View Portfolio Samples →](index.html)**

### 01 — Digital Services Overview

A public-facing DHS OCIO-style content page focused on making technical information easier for users to understand.

**Highlights**
- Federal plain-language principles
- Clear, scannable content structure
- Semantic HTML and heading hierarchy
- Accessible navigation and keyboard focus
- Responsive design
- Content ownership and review information

## Purpose

The goal of this project is to demonstrate both the **content and technical sides of federal web management** — from writing clear public-facing content to publishing through a CMS, identifying accessibility issues, coordinating remediation, performing QA, and documenting the final results.
